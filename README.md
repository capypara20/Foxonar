<h1 align="center">Foxonar</h1>

<p align="center">日本語 | <a href="README.en.md">English</a></p>

フォルダを見張り、ファイルが来た・変わった・消えたことを検知して、決めておいたジョブ（コピー、移動、プログラムの起動など）を走らせる常駐アプリです。Rust で作ります。

> [!NOTE]
> **今は設計の段階です。** 動くプログラムは、まだありません。決まったことは [設計書](docs/design.ja.md) にまとめています。

## 動きの例

```
C:\inbox に cat.jpg が来た
  │  書き込みが終わるのを待つ
  ▼
トリガー「写真が来たら」（監視フォルダ inbox・作成・*.jpg）に合う
  │
  ├─ ジョブ「サムネイル」 ─┐
  └─ ジョブ「バックアップ」┘ 並行に走る
        │
        ▼
結果はランログに残り、ブラウザの画面（Web UI）で見られる
```

## できること（予定）

- **見張る**：Windows と Linux（画面のないサーバーも）。監視フォルダごとに、見る深さや、隠しファイルを含むかを決められる
- **見分ける**：作成・変更・削除・名前変更・移動。大きなファイルのコピーや Word の保存のように、OS から細かく何度も知らせが来ても、1 つの変化にまとめる
- **待つ**：書き込みが終わってからジョブを走らせる。フォルダごとコピーしたときは、中身がそろうまで待つ
- **走らせる**：コピー・移動・削除と、プログラムの起動（プロセス実行）。シェルを通さないので、ファイル名がコマンドとして実行されることは無い
- **残す**：検知した変化はすべて検知ログに、ジョブの結果はランログに残す。ジョブを書かなくても、どんなファイルが来たかを確かめられる。ジョブが走らなかったときも、その理由がランログで分かる
- **知らせる**：来た・成功した・失敗したのどれをデスクトップ通知で知らせるかを選べる
- **設定する**：TOML のファイル。ブラウザの画面からも書け、書き換えたら自動で読み直す

## 開発

- 言語：Rust 1.98.1（`rust-toolchain.toml` で決める）
- 主に WSL（Ubuntu-24.04）で開発し、Windows 向けのビルドも WSL から行う。くわしくは [設計書 9.1](docs/design.ja.md#91-開発のしかた)
- AI エージェント（Claude Code など）と一緒に設計している。AI 向けの説明書は [AGENTS.md](AGENTS.md)
